# AVIA Theme

Aplicativo oficial de tema e máscara visual do **ERP AVIA** (Grupo Belchior).

Este aplicativo desacopla 100% das customizações visuais (Login customizado, Dock flutuante lateral, estilos do Desk, imagens e logotipos) do código-fonte do Frappe e do ERPNext.

Dessa forma, atualizações de segurança e novas versões da comunidade Frappe/ERPNext podem ser aplicadas (`bench update`) sem risco de conflito ou perda de personalizações.
